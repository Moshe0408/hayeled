# ⚽ הילד מהשכונה

**מהשכונה ועד הבאלון ד'אור.**

משחק קריירה של כדורגלן, בעברית, לטלפון. מתחילים בגיל 15 במחלקת הנוער ועוברים קריירה שלמה: נבחרות נוער, חוזה מקצועני ראשון, השאלות והעברות לליגות גדולות, ליגת האלופות, גביע המדינה, הנבחרת (מוקדמות, יורו ומונדיאל), פרסים, פרישה, ובסוף היכל התהילה.
אמא מבשלת, אבא ביציע, קבוצת הווטסאפ של החבר'ה לא שותקת, והסוכן תמיד "יש לו משהו גדול".

## 🎮 לשחק עכשיו

**https://moshe0408.github.io/hayeled/**

אין צורך בהורדה מחנות ואין צורך בהרשמה. המשחק עובד גם בלי אינטרנט אחרי הפתיחה הראשונה.

## איך משחקים

1. **יוצרים שחקן:** שם, כינוי, נבחרת, עמדה, רגל חזקה ומחלקת נוער.
2. **כל תור הוא שבוע:** בוחרים אימון, קוראים הודעות ולוחצים "שחק את השבוע".
3. **במשחקים שלך** מגיעים 3 עד 7 רגעי מפתח. בכל רגע בוחרים מה לעשות, ולכל אפשרות מוצג סיכוי (נמוך, בינוני או גבוה). אפשר גם "שחק אוטומטית".
4. **הודעות בסגנון ווטסאפ** מהמשפחה, מהחברים, מהסוכן, מהמאמן ומהעיתונאים. כל תשובה משפיעה על המורל, על אמון המאמן ועל אהבת הקהל.
5. **הצעות העברה** מגיעות בחלונות ההעברות (קיץ וחורף). אפשר לקבל, לדחות או לנהל משא ומתן על שכר, שנים, תפקיד וסעיף שחרור.
6. **הרצה מהירה ⏩** עד המשחק הבא או עד סוף העונה. עונה שלמה לוקחת בערך 10 עד 15 דקות.
7. **פרישה:** אפשר לפרוש מגיל 32. הקריירה נכנסת להיכל התהילה עם ציון מורשת.

## 📲 התקנה בטלפון (מומלץ)

**אנדרואיד (Chrome):**
פותחים את הקישור. אם מופיע כפתור "התקן" במשחק, לוחצים עליו. אם לא: תפריט ⋮ ואז "הוספה למסך הבית" (או "התקנת אפליקציה").

**אייפון / אייפד (Safari):**
פותחים את הקישור **ב-Safari**, לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה), ואז "הוסף למסך הבית".

> ⚠️ **חשוב באייפון:** למשחק שמותקן במסך הבית יש אחסון **נפרד** מ-Safari. קריירה שהתחלת ב-Safari לא תופיע באפליקציה המותקנת. לפני ההתקנה: הגדרות ← "העתק קוד גיבוי" ב-Safari, ואחרי ההתקנה מייבאים את הקוד בתוך האפליקציה.

## 💾 איך ההתקדמות נשמרת

- **שמירה אוטומטית** אחרי כל פעולה, כל משחק וכל החלטה, וגם ברגע שסוגרים את האפליקציה או עוברים לאפליקציה אחרת.
- **שמירה כפולה במכשיר:** כל שמירה נכתבת לשני מקומות בדפדפן (localStorage ו-IndexedDB). לכל עותק יש בדיקת תקינות. אם אחד מהם נמחק או נפגם, המשחק משחזר אותו מהשני אוטומטית.
- **שמירה קודמת:** המשחק שומר גם את המצב מתחילת השבוע הקודם במשחק. בהגדרות יש "שחזר שמירה קודמת", ואפשר לבטל את השחזור באותו כפתור.
- **3 משבצות שמירה.** משבצת שנמחקה אפשר לשחזר מתפריט המשבצת במסך הפתיחה.
- **היכל התהילה נשמר בנפרד** ונשאר תמיד, גם כשמוחקים משבצת או מתחילים קריירה חדשה.
- **הגנה על האחסון:** המשחק מבקש מהדפדפן לא למחוק את הנתונים (`navigator.storage.persist`). הסטטוס מופיע בהגדרות.
- **גיבוי ידני ומעבר לטלפון אחר:** הגדרות ← "ייצוא קובץ" (קובץ `.json`) או "העתק קוד גיבוי" (טקסט שאפשר לשלוח לעצמך בווטסאפ). בטלפון החדש: הגדרות ← ייבוא מקובץ או הדבקת קוד. יש גם "גיבוי מלא", שכולל את כל המשבצות ואת היכל התהילה.

**מה כן יכול למחוק את ההתקדמות?** ההתקדמות נשמרת על המכשיר ולא בשרת. מחיקת נתוני הדפדפן או נתוני האתר (או הסרת האפליקציה באייפון) מוחקת אותה. ב-Safari שלא הותקן למסך הבית, iOS עלול למחוק נתוני אתר אחרי כ-7 ימים בלי ביקור. לכן מומלץ להתקין את המשחק למסך הבית ולייצא גיבוי מדי פעם.

## 🛠️ מנהל, סטטיסטיקות, משוב ופרסומות

למשחק יש לוח ניהול (`admin.html`): כמה שחקנים יש, כמה מחוברים עכשיו, כמה משחקים שוחקו, דירוגים ומשובים, הגדרות מרחוק, הודעה לכל השחקנים ופרסומות (כבויות כברירת מחדל).
הכול מבוסס על פרויקט Supabase חינמי. עד שמגדירים אותו, המשחק עובד במלואו בלי שרת ולא שולח שום דבר.

**מדריך הקמה צעד אחר צעד: [docs/ADMIN_SETUP.md](docs/ADMIN_SETUP.md)**

הנתונים שנאספים אנונימיים בלבד (מזהה מכשיר אקראי, זמן משחק ואירועים במשחק), בלי שם, בלי מיקום ובלי אנשי קשר. השחקן יכול לכבות את השיתוף בהגדרות.

## 🚀 פרסום עדכון (לבעלים)

מריצים מתוך התיקייה של המשחק:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Message "ליגות חדשות"
```

הסקריפט מעלה את מספר הגרסה ב-`sw.js` וב-`js/config.js` (אפשר לדלג עם `-NoBump`), מבצע commit ו-push ל-`main`, ומדפיס את הקישור. העלאת הגרסה גורמת לכך שבטלפונים יופיע "גרסה חדשה זמינה". ההתקדמות של השחקנים לא נפגעת מעדכון.
בפעם הראשונה בלבד: ב-GitHub נכנסים ל-Settings ← Pages ← Deploy from a branch ← `main` / `(root)`.

## 💻 הרצה מקומית ובדיקות

```bash
node tests/serve.mjs 8080 --base /hayeled/     # http://localhost:8080/hayeled/
node tests/save.test.mjs                       # בדיקות מערכת השמירה (שמירה כפולה, שחזור, מכסה, ייבוא וייצוא)
node tests/sim.mjs --quick                     # סימולציית קריירות מלאה בלי דפדפן
node tests/mock-supabase.mjs 54329             # שרת Supabase מדומה לבדיקות
cd tests && npm install && node e2e.mjs        # בדיקות קצה לקצה עם Chrome (puppeteer-core)
node tools/make-icons.mjs                      # יצירה מחדש של האייקונים
```

אין שלב build ואין תלויות ריצה: HTML, CSS ו-JavaScript (ES modules) נטענים כמו שהם, עם כתובות יחסיות בלבד, כך שהמשחק עובד גם תחת `/hayeled/` וגם בשורש של שרת.

## English (short)

**HaYeled MeHaShchuna** ("the kid from the neighbourhood") is a Hebrew, RTL, mobile-first football **player career** game. It is a static PWA with no build step and no runtime dependencies. Play it at **https://moshe0408.github.io/hayeled/**.

- **Run locally:** `node tests/serve.mjs 8080 --base /hayeled/` → http://localhost:8080/hayeled/
- **Tests:** `node tests/save.test.mjs` (storage), `node tests/sim.mjs --quick` (headless engine), `tests/e2e.mjs` (puppeteer-core, see `docs/SPEC.md` §10).
- **Deploy:** `publish.ps1` bumps `APP_VERSION` and the `sw.js` `VERSION` together, then commits and pushes `main`. GitHub Pages serves the repo root (`.nojekyll` is present).
- **Saves:** dual on-device storage (localStorage + IndexedDB mirror) with checksums, sequence numbers, self-healing, a weekly rollback copy, 3 slots, a separately stored Hall of Fame, and JSON/code export and import. See `docs/SPEC.md` §7.
- **Backend (optional):** Supabase for anonymous telemetry, feedback, remote config, ads and the admin dashboard (`admin.html`). See `docs/ADMIN_SETUP.md`.

### File structure

```
index.html              game shell              admin.html        admin dashboard (noindex)
manifest.webmanifest    PWA manifest            sw.js             service worker (versioned cache)
css/app.css             game styles             css/admin.css     admin styles
js/main.js              boot, autosave, SW update flow
js/config.js            APP_VERSION, Supabase URL + anon key (empty = offline only)
js/core/                rng, save + idb (storage), supa, telemetry, remote, feedback, ads
js/data/                countries, leagues, names, events, commentary, strings (Hebrew)
js/engine/              pure, DOM-free game engine; game.js is the facade used by the UI
js/ui/                  screens and components
js/admin/               admin dashboard modules
icons/                  icon.svg + PNG icons (generated by tools/make-icons.mjs)
supabase/schema.sql     database schema, RLS and RPCs
docs/                   SPEC.md (technical spec), ADMIN_SETUP.md (owner guide, Hebrew)
tests/                  serve.mjs, save.test.mjs, sim.mjs, mock-supabase.mjs, e2e.mjs
tools/make-icons.mjs    zero-dependency PNG icon generator
publish.ps1             one-command publish to GitHub Pages
```
